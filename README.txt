# MÁDERA E-Commerce

مشروع واجهة متجر MÁDERA.

## الملفات

- index.html — هيكل الموقع
- style.css — التصميم والألوان والـ responsive
- script.js — المنتجات والسلة والبحث والمفضلة

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو افتح مجلد المشروع في VS Code واستخدم Live Server.

## مهم

النسخة الحالية Front-End. السلة تعمل محليًا باستخدام LocalStorage.

المرحلة التالية يمكن إضافة:
1. قاعدة بيانات حقيقية.
2. لوحة تحكم لإضافة وتعديل المنتجات.
3. تسجيل العملاء والطلبات.
4. رفع صور المنتجات من لوحة التحكم.
5. الدفع الإلكتروني في مصر.
6. WhatsApp للطلبات.
7. استضافة ودومين باسم MÁDERA.
